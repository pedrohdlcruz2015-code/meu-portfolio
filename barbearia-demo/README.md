# Navalha Urbana

Projeto demonstrativo de um site para uma barbearia fictícia.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Página inicial
- Seção sobre
- Catálogo de serviços
- Galeria de imagens
- Navegação entre seções
- Layout responsivo

## Objetivo
Demonstrar habilidades de desenvolvimento web e criação de interfaces.
